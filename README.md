# Arquitectura-De-Hardware
Trabajos finales

Análisis: El trabajo demuestra un muy buen nivel de programación. El uso de estructuras de datos, máquinas de estados, temporización mediante millis() y control por solicitudes mediante sensores refleja una comprensión sólida del desarrollo de sistemas embebidos. Sin embargo, la evaluación del taller no solo contempla la implementación del código, sino también el diseño funcional del sistema de semaforización. La ausencia del diagrama de flujo y del diseño de la intersección impide verificar completamente la lógica operacional y la seguridad del sistema. Además, la transición simultánea a amarillo de dos grupos constituye un aspecto que debe corregirse para cumplir con las buenas prácticas de control semafórico.
